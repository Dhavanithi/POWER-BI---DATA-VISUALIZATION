# Netflix Stock Analysis Dashboard

## About the Project

This project is a Power BI dashboard created to understand and analyze Netflix stock data.

I wanted to make the dashboard simple and easy to understand while still showing different aspects of the stock performance. The dashboard mainly focuses on stock prices, trading volume, moving averages and the relationship between different price values.

## Tools Used

- Power BI
- DAX
- Stock market dataset
- Data visualization

## What the Dashboard Shows

The dashboard contains different visuals to understand the stock data:

- Average Open price
- Average Close price
- Average High price
- Average Low price
- Average Adjusted Close
- Average Trading Volume
- 20-day moving average
- 50-day moving average
- Trading volume over time
- Open vs Close comparison
- Date range filtering

## Dashboard Features

### KPI / Stock Metrics

The top section contains KPI visuals for the main stock values. These help to quickly check the average Open, Close, High and Low prices.

### Moving Average Analysis

I used 20-day and 50-day moving averages to observe how the stock price changes over time.

The moving average charts make it easier to see the general trend instead of looking at every individual price point.

### Trading Volume

The volume chart shows how the trading volume changes with time. This helps in understanding periods where the trading activity was higher or lower.

### Open and Close Analysis

The dashboard also includes a comparison between Open and Close prices.

A scatter plot is used to see the relationship between the opening and closing prices.

### Date Filter

A date slicer is included in the dashboard so that the data can be viewed for a selected period.

## Dashboard

The dashboard covers the stock data across the available period and provides different views instead of depending on a single chart.

The main dashboard title is:

**NETFLIX STOCK ANALYSIS**
