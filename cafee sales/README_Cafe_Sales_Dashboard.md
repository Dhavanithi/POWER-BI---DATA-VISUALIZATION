# Cafe Sales Analysis Dashboard

## Project Overview

This project is a **Cafe Sales Analysis Dashboard**.

The dashboard analyzes cafe sales data and provides interactive insights
into sales performance, monthly trends, payment methods, and key sales
metrics.

## Objectives

-   Analyze overall cafe sales performance.
-   Track sales using different time periods.
-   Monitor Monthly, Quarterly, and Yearly sales.
-   Identify sales trends over time.
-   Analyze sales based on payment methods.
-   Present important business metrics using KPI cards.

## Tools & Technologies

-   Microsoft Power BI
-   Power Query
-   DAX
-   Data Visualization

## Dashboard Features

### KPI Cards

The dashboard contains five KPI cards:

1.  Total Sales
2.  Sales MTD (Month-to-Date)
3.  Sales QTD (Quarter-to-Date)
4.  Sales YTD (Year-to-Date)
5.  Previous Comparison

### Visualizations

#### Line Chart -- Monthly Sales Trend

Shows how total cafe sales change across different months.

#### Donut Chart -- Sales by Payment Method

Shows the contribution of different payment methods to total sales.

## Key Measures

The dashboard uses DAX measures such as:

-   Total Sales
-   Sales MTD
-   Sales QTD
-   Sales YTD
-   Previous Comparison

## Dataset

The dataset contains cafe transaction information such as:

-   Date
-   Item
-   Location
-   Payment Method
-   Price Per Unit
-   Quantity
-   Total Spent
-   Transaction Details

## KPI Targets

The dashboard uses the following sample target values for KPI
visualization:

  KPI             Target
  ------------- --------
  Total Sales     30,000
  Sales MTD        3,000
  Sales QTD        8,000
  Sales YTD       35,000

These are dashboard visualization targets and should not be interpreted
as official business targets unless defined by the business.

The dashboard helps users understand:

-   Overall sales performance

-   Sales performance compared with previous periods

## How to Use

1.  Open the `.pbix` file using Microsoft Power BI Desktop.
2.  Refresh the data if required.
3.  Use the available filters and visuals to explore the sales data.
4.  Interact with the KPI cards and charts to analyze sales performance.
